# Visual Reference Workflow

Запуск: `python3 reference_app/server.py`, затем открыть http://127.0.0.1:8765. При необходимости изменить порт: `PORT=8766 python3 reference_app/server.py`. Python 3.9+; внешние пакеты не нужны. Сервер доступен только на этом компьютере.

Карточки хранятся в `reference_app/references.sqlite3`; для резервной копии остановите сервер и скопируйте этот файл. Удаление карточки не удаляет исходные файлы. Превью можно указать прямой ссылкой или путём `/archive/images/Референсы/имя_файла.jpg`. Внешние сайты могут запрещать показ изображений. Автоматического импорта, публикации и синхронизации с Instagram, Notion или Figma нет.

В `archive_index.json` 120 записей с существующими локальными изображениями. Возможная миграция: сначала сформировать список-кандидат из индекса, сохранить исходную запись целиком и путь к файлу, проверить совпадения и источники, затем явно подтвердить импорт. Исходный индекс и файлы при этом не изменять; автоматическое объединение потенциальных дублей не выполнять. Дата старых записей может быть неизвестна и не должна выдаваться за дату первоначального сохранения.

Доска: выберите «Доска» и добавьте изображения из архива. Выделенное изображение можно перемещать, изменять за угол и редактировать через кнопку с карандашом. Яркость, контраст, насыщенность, чёрно-белый эффект и поворот сохраняются только в композиции доски; исходные изображения не изменяются. Удаление с доски не удаляет файл. Доска хранится в том же SQLite-файле, что и карточки. Экспорт отредактированных изображений и совместное редактирование пока не реализованы.

Архив читает оба варианта пути в индексе: `relative_path` и `local_path`, поэтому локально сохранённые записи Are.na также видны в библиотеке и выбираются для доски. Сбор новых материалов выполняется отдельно сборщиком проекта `visual-reference-pipeline`; приложение не загружает их автоматически.

Обрезка на доске задаётся ползунками для четырёх краёв; доступны также отражение и прозрачность. Для новых изображений рамка создаётся по исходным пропорциям, а прежние рамки подстраиваются при открытии доски. Исходные файлы не редактируются.

«Коллаж» собирает материалы архива в готовую или собственную сетку (до 6×6), поддерживает изменение отступов, формата и экспорт PNG. «Редактор» открывает локальный файл, применяет настройки и обрезку без изменения оригинала и сохраняет результат в PNG. Черновики этих двух режимов существуют только до перезагрузки страницы; сохранённая доска остаётся в SQLite. Для экспорта сторонние изображения должны разрешать браузеру доступ к своим данным.

В редакторе можно добавлять текст выбранным шрифтом, удалять загруженную фотографию и отменять или повторять действия (кнопки либо Cmd/Ctrl+Z и Cmd/Ctrl+Shift+Z). История хранится до закрытия страницы или удаления фото. Westernic, Nighthawk и Instrument Serif — декоративные шрифты с латиницей; Inter доступен для кириллицы. Исходники шрифтов и лицензия указаны в `fonts/README.md`.

Во «Всех референсах» можно создавать, переименовывать и удалять папки. Через кнопку «В папку» на карточке добавляются ссылки на материалы библиотеки или архива; удаление папки не удаляет материалы. Папки и их содержимое сохраняются в SQLite. Тема и язык находятся в настройках и сохраняются в данном браузере. Статусы интеграций описывают возможности приложения, а не проверяют действующую авторизацию внешних сервисов.

Видео можно добавить через карточку: выберите файл MP4, WebM, MOV или OGV до 512 МБ либо укажите прямую ссылку на видео в поле превью. Файл копируется в `reference_app/uploads` при сохранении карточки, воспроизводится в карточке и может быть размещён на доске; поддержка конкретного кодека зависит от браузера. Плеер поддерживает перемотку. При удалении карточки локальный видеофайл сохраняется; для резервной копии скопируйте папку `uploads` вместе с SQLite. Видеоролики не включаются в изображения коллажа и не редактируются в отдельном фоторедакторе.
